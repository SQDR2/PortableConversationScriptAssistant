## ADDED Requirements

### Requirement: 组合内容复制

系统必须支持将话术文本和关联的图片同时写入系统剪贴板，以便粘贴到支持富文本的应用（如微信、飞书）。

#### Scenario: 点击带图片话术的复制按钮

- **WHEN** 用户点击一个包含图片的话术的“复制”按钮
- **THEN** 系统构造一个包含 `<img>` 标签的 HTML 片段，并将文本和 HTML 同时存入剪贴板

### Requirement: 剪贴板兼容性

对于不支持 HTML 粘贴的应用，系统必须提供纯文本作为回退（Fallback）。

#### Scenario: 粘贴到记事本

- **WHEN** 用户复制了图文话术并尝试粘贴到记事本
- **THEN** 记事本应展示话术的纯文本内容，忽略 HTML 部分

### Requirement: 多图同步复制

当话术附有多张图片时，系统必须将全部图片与文本一并写入剪贴板，不得仅复制第一张。

#### Scenario: 点击含多张图片的话术

- **WHEN** 用户点击一个附有三张图片的话术的内容区域
- **THEN** 系统构造一个包含三个 `<img>` 标签的 HTML 片段，并将文本和 HTML 同时存入剪贴板

#### Scenario: 无图片话术不走 HTML 路径

- **WHEN** 用户点击一个没有图片的话术的内容区域
- **THEN** 系统使用 `writeText()` 写入纯文本，不构造任何 HTML

### Requirement: 复制反馈文案区分

系统必须根据话术是否含图片，向用户展示不同的复制成功提示，使用户明确知道复制了什么内容。

#### Scenario: 图文话术复制成功提示

- **WHEN** 用户复制了含图片的话术
- **THEN** 系统提示"已复制图文内容"，而非"已复制文本内容"

#### Scenario: 纯文本话术复制成功提示

- **WHEN** 用户复制了没有图片的话术
- **THEN** 系统提示"已复制文本内容"，与现有行为一致
