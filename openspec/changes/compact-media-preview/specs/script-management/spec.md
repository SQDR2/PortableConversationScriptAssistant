## MODIFIED Requirements

### Requirement: 话术列表媒体预览尺寸

话术列表中，内嵌媒体预览区域的高度必须保持紧凑，以确保文字内容在视觉上优先于媒体内容。

#### Scenario: 单张图片预览高度

- **WHEN** 话术包含一张图片并在列表中展示
- **THEN** 图片预览高度不超过 120px，宽度撑满卡片内容区

#### Scenario: 多张图片 grid 预览高度

- **WHEN** 话术包含多张图片并在列表中展示
- **THEN** 每张图片缩略图高度为 80px，排列在两列网格中

#### Scenario: 视频预览高度上限

- **WHEN** 话术包含视频并在列表中展示
- **THEN** 视频预览高度不超过 160px，超出部分通过视频播放器自身处理
