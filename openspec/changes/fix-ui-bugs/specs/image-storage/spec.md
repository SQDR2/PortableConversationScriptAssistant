## ADDED Requirements

### Requirement: 图片上传组件每次选择后重置内部状态

图片上传组件在用户完成一次文件选择后（无论成功或失败），MUST 立即重置内部的 model value 状态，确保后续上传操作能正常触发文件变更事件。打开编辑器时也 MUST 重置上传组件状态。

#### Scenario: 连续上传两张图片

- **WHEN** 用户在同一编辑会话中先后选择两张不同图片
- **THEN** 两次上传均成功保存并显示在附件列表中

#### Scenario: 选择相同文件名再次上传

- **WHEN** 用户先上传一张图片，然后再次选择同名文件
- **THEN** 第二次上传仍能正常触发并保存

#### Scenario: 上传失败后再次上传

- **WHEN** 第一次上传失败后用户再次尝试上传
- **THEN** 第二次上传能正常触发
