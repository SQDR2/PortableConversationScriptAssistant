## ADDED Requirements

### Requirement: 话术列表为唯一可滚动区域

话术管理页面中，搜索栏和视图切换器 MUST 保持固定在页面顶部，不随列表滚动。滚动条 MUST 仅出现在话术列表容器内部，页面级别 MUST 禁止滚动。

#### Scenario: 列表内容超出可视区域

- **WHEN** 话术数量超出当前可视区域高度
- **THEN** 仅话术列表区域出现垂直滚动条，搜索栏和视图切换按钮保持固定在顶部

#### Scenario: 翻译栏显隐切换

- **WHEN** 用户切换翻译栏的显示/隐藏状态
- **THEN** 话术列表区域的可用高度自动调整，搜索栏和视图切换器仍然保持固定
