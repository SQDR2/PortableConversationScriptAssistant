## Context

`ScriptItem.vue` 的内嵌媒体区域（`.script-media`）当前尺寸：单图 max-height 200px、多图 grid 行高 120px、视频无高度上限。在话术列表密集展示场景下，媒体内容占比过高。

## Goals / Non-Goals

**Goals:**
- 减少媒体预览区垂直高度，提升话术列表密度
- 视频添加高度上限，防止超长视频撑开卡片

**Non-Goals:**
- 不改变媒体的交互行为（点击放大、右键菜单、全屏播放）
- 不改变 HTML 结构或任何 JS 逻辑
- 不处理缩略图条等复杂布局重构

## Decisions

### 仅修改 CSS 数值，不调整结构

**选择**：直接修改 `.script-media-images` 和 `.script-media-video` 的高度数值。

**原因**：范围最小、风险最低，与"最小方案"设计目标一致。现有 `object-fit: cover` 保证裁剪质量，无需额外处理。

### 数值选择依据

| 元素 | 修改前 | 修改后 | 依据 |
|------|--------|--------|------|
| 单图 | 200px | 120px | 保留足够预览空间，同时减少40%高度 |
| 多图 grid | 120px | 80px | 统一缩小，2列布局中80px仍清晰可辨 |
| 视频 | 无上限 | max-height: 160px | 与单图差不多比例，防止视频撑高话术卡 |

## Risks / Trade-offs

- 图片细节可见度略降，但用户可点击放大查看完整内容，影响可接受
- 无迁移、无回滚复杂度，CSS 数值随时可调整
