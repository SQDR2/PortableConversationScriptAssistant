## Context

当前话术助手仅支持纯文本存储。为了增强用户体验，需要引入图片附件支持。项目使用 Wails + Vue + Quasar，数据存储在本地 SQLite 数据库中。

## Goals / Non-Goals

**Goals:**

- 支持话术关联多张本地图片。
- 实现平滑的图片上传、预览体验。
- 支持将话术文案与图片一并复制到剪贴板，并兼容常用社交软件（如微信）。

**Non-Goals:**

- 不支持云端同步图片（本阶段仅限本地）。
- 不支持图片在线编辑（滤镜、裁剪等）。

## Decisions

### 1. 图片存储策略

**选择**: 将图片文件保存在本地磁盘 `scripts_images` 文件夹中，数据库仅记录相对路径。

- **原因**: 避免 SQLite 数据库因 Blob 数据过大而性能下降。
- **命名规则**: 使用 **UUID V7** 生成文件名，确保唯一性。

### 2. 剪贴板实现方案

**选择**: 通过 Wails 调用后端 Go 函数，利用系统级 API 写入富文本（HTML）剪贴板。

- **原因**: 前端 `navigator.clipboard` 在处理本地路径图片时安全性限制较多，后端 Go 可以更稳定地构造并发送 `CF_HTML` (Windows) 或类似格式的数据。

### 3. 数据模型

**选择**: 在 `models.Script` 结构体中增加 `Images` (string) 字段，存储 JSON 编码的路径数组。

- **原因**: 考虑到话术图片的数量通常较少（1-10张），JSON 字符串在 SQLite 中查询简单且不需要引入复杂的联表结构。

## Risks / Trade-offs

- **[Risk] 图片文件残留** → **[Mitigation]** 在 `DeleteScript` 方法中增加钩子，同步删除对应的物理文件。
- **[Trade-off] 剪贴板格式兼容性** → 不同应用对 HTML 剪贴板的支持程度不一。我们将同时写入纯文本和 HTML 内容，确保在不支持图片的编辑器中仍能粘贴出文字。
