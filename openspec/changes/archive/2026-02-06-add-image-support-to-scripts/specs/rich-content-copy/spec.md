## ADDED Requirements

### Requirement: 组合内容复制

系统必须支持将话术文本和关联的图片同时写入系统剪贴板，以便粘贴到支持富文本的应用（如微信、飞书）。

#### Scenario: 点击带图片话术的复制按钮

- **WHEN** 用户点击一个包含图片的话术的“复制”按钮
- **THEN** 系统构造一个包含 `<img>` 标签的 HTML 片段，并将文本和 HTML 同时存入剪贴板

### Requirement: 剪贴板兼容性

对于不支持 HTML 粘贴的应用，系统必须提供纯文本作为回退（Fallback）。

#### Scenario: 粘贴到记事本

- **WHEN** 用户复制了图文话术并尝试粘贴到记事本
- **THEN** 记事本应展示话术的纯文本内容，忽略 HTML 部分
