## ADDED Requirements

### Requirement: 多图同步复制

当话术附有多张图片时，系统必须将全部图片与文本一并写入剪贴板，不得仅复制第一张。

#### Scenario: 点击含多张图片的话术

- **WHEN** 用户点击一个附有三张图片的话术的内容区域
- **THEN** 系统构造一个包含三个 `<img>` 标签的 HTML 片段，并将文本和 HTML 同时存入剪贴板

#### Scenario: 无图片话术不走 HTML 路径

- **WHEN** 用户点击一个没有图片的话术的内容区域
- **THEN** 系统使用 `writeText()` 写入纯文本，不构造任何 HTML

### Requirement: 复制反馈文案区分

系统必须根据话术是否含图片，向用户展示不同的复制成功提示，使用户明确知道复制了什么内容。

#### Scenario: 图文话术复制成功提示

- **WHEN** 用户复制了含图片的话术
- **THEN** 系统提示"已复制图文内容"，而非"已复制文本内容"

#### Scenario: 纯文本话术复制成功提示

- **WHEN** 用户复制了没有图片的话术
- **THEN** 系统提示"已复制文本内容"，与现有行为一致
