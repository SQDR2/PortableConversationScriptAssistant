## ADDED Requirements

### Requirement: 图片右键自定义菜单

应用内显示的图片 SHALL 支持右键单击操作，展示包含"复制图片"和"在文件夹中显示"两个选项的上下文菜单。此行为必须在生产构建（`wails build`）和开发模式（`wails dev`）下均正常工作，不依赖浏览器原生右键菜单。

#### Scenario: 用户右键单击图片，选择「复制图片」

- **WHEN** 用户在话术卡片或详情预览中右键单击任意图片
- **THEN** 系统弹出包含「复制图片」和「在文件夹中显示」的上下文菜单

#### Scenario: 点击「复制图片」后图片被写入剪贴板

- **WHEN** 用户在右键菜单中点击「复制图片」
- **THEN** 系统通过 `fetch + ClipboardItem` API 将图片以 PNG 格式写入系统剪贴板，并弹出「图片已复制」的成功通知

#### Scenario: 图片复制失败时降级处理

- **WHEN** `ClipboardItem` 写入失败（如 MIME 类型不支持或权限拒绝）
- **THEN** 系统弹出错误通知，提示用户通过「在文件夹中显示」手动获取文件
